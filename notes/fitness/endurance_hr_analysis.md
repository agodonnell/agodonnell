# Cadence and Torque Analysis

During steep climbs:

| Metric | Value |
|------|------|
| Cadence | ~68 rpm |
| HR plateau | 150–155 bpm |

Low cadence increases **torque per pedal stroke**.

Power relationship:

```
Power = Torque × Cadence
```

When cadence drops, torque must increase.

This shifts the workload toward:

- muscular endurance
- connective tissue load
- force production

Therefore the **muscles become the limiter before cardiovascular capacity is reached**.

# Marathon Heart Rate Strategy

Marathon pace is typically:

```
88–92% of Lactate Threshold HR
```

Using LT ≈160 bpm:

| % LT | HR |
|------|------|
| 85% | 136 |
| 88% | 141 |
| 90% | 144 |
| 92% | 147 |

Recommended pacing strategy:

| Race Phase | HR Target |
|------|------|
| Miles 1–8 | 135–140 |
| Miles 8–20 | 140–145 |
| Miles 20–26 | 145–150 |

Pulling back when HR reaches **139 bpm** is conservative but effective.
